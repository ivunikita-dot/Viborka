Инструкция по сборке готового Windows onefile .exe (PyInstaller) через GitHub Actions

Цель
- Собрать один исполняемый файл dist/выборка.exe на Windows (onefile, windowed) без необходимости ручной настройки сборки на вашей машине.
- Workflow использует Windows runner (windows-latest) и автоматически добавляет нужные ресурсы Tcl/Tk, если они доступны в окружении.

Как использовать
1) Создайте новый репозиторий на GitHub (например my-find-fio-builder).
2) Скопируйте все файлы из этого архива/папки в корень репозитория и закоммитьте (включая find_fio_gui_recursive_v5.py, build_exe.py, requirements.txt, doom.ico если у вас есть).
3) Push на GitHub.
4) Откройте вкладку Actions в репозитории — workflow "build-windows.yml" должен отобразиться. Запустите его вручную (если enabled) или просто сделайте push — он запустится автоматически.
5) После выполнения workflow зайдите в панель Actions → выберите последний запуск → в правой части найдите артефакты (Artifacts) и скачайте dist-выборка.

Примечания
- Если вы хотите добавить иконку DOOM, поместите doom.ico в корень репозитория перед push.
- Размер exe может быть большим (десятки мегабайт). Антивирусы иногда сообщают о ложных срабатываниях — это нормальная ситуация для самодельных .exe.
- Если возникнут ошибки в процессе сборки, пришлите лог из Actions — помогу исправить.
